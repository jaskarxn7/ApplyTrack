# ApplyTrack
Placement application dashboard built with JavaScript, HTML, and CSS.

ApplyTrack is a single-page web dashboard I built to track placement and job applications in one place without needing spreadsheets.

 What it does?
- Log company names, job titles, application dates, deadlines, and status updates (Applied, Interview, Offer, Rejected).
- Search and filter applications live by company name or application status.
- Saves all your application data directly in your browser using `LocalStorage`.

Tech stack?
- HTML & CSS
- JavaScript 
- LocalStorage API
